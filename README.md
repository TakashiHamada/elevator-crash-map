# エレベーター事故マップ

架空の「霧原市」を舞台にしたWeb ARGの静的プロトタイプです。HTML・CSS・JavaScriptのみで実装しており、外部ライブラリ、地図API、ビルド、APIキーは不要です。

## 起動

このディレクトリで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://localhost:8000` にアクセスします。投稿・公開状態をページ間で共有するため、HTTP経由での起動を推奨します。`file://` で直接開く場合、ブラウザーによって保存や共有が制限されます。

## 操作

- 地図のドラッグ、ホイール、＋／−、タッチのピンチで移動・拡大縮小。
- 赤い事故アイコンを選択すると記録を表示。
- 町名・建物名・記録番号の検索、発生年代による絞り込み。
- ⌖ で表示・検索条件をリセット。
- 記録のURLは `#record=KR-010` などで直接指定可能。リンクコピーにはブラウザーのクリップボード許可が必要な場合があります。
- 地図にフォーカスして矢印キーで移動、＋／−でズーム。Escで記録を閉じる。

## 編集

- `data.js`：事故記録、地図ラベル、座標、ズーム設定。座標は元画像に対する0〜100の百分率。ピンチ感度は `MAP_CONFIG.pinchSensitivity`（現在3、従来の感度は1）で調整できます。
- `style.css`：色、文字サイズ、マーカーサイズ（`--marker-size`）、掲示板幅（`--board-share`）など。
- `board-data.js`：噂5件、保留投稿10件、住所の選択肢10箇所（`ARG_CONFIG.reportAddresses`）、管理者紹介、ロゴクリック回数、仮パスワード、消去演出時間。
- `community.js`：投稿、公開、ドロワー、ブラウザー保存、秘密の導線、終了状態。
- `assets/kirihara-map.png`：生成した架空の街の地図。
- `assets/elevator-crash.png`：生成した破損エレベーターアイコン。

地図は一枚の画像なので、ズームしても道路情報が増える方式ではありません。市外の実在地図には接続しません。小さな画面では一部が画面外になりますがドラッグして閲覧できます。バックエンド・外部送信はありません。投稿と進行状況は localStorage に保存されます。

参考UI：https://www.oshimaland.co.jp/ （地図・地点アイコン・検索・記録閲覧という構成を参考。）

## 画像生成

内蔵 image_gen で生成。プロンプトは `assets/prompts.md` に保存しています。地図・建物・事故・出典はすべて架空です。

## 掲示板とゲームの流れ

- PC（761px以上）：左25%が掲示板、右75%が地図の領域。掲示板は縦スクロールできます。
- スマートフォン（760px以下）：地図の下に掲示板、投稿フォーム、管理者紹介リンクが続きます。
- 噂と管理者紹介はドロワーで表示。閉じるボタン、背景クリック、Escで閉じられます。スマートフォンでは下から開きます。
- 住所は市内10箇所からプルダウンで選択し、内容とともに保留一覧に追加。住所は選択必須、内容は空白のみの入力不可・上限3000文字です。
- トップ左上のタイトルロゴを同じページ内で10回クリックすると、ランダムな160ビットの文字列を含む管理者ページへ移動します。URLは `board-data.js` の `adminPath` にあります。
- 保留投稿の「表側に表示する」で公開。公開操作の新しい順にトップ5へ入り、古い項目は一覧から押し出されます。公開済みデータは保存され、再公開による重複を防ぎます。
- 同じブラウザー・同じオリジンの別タブにも公開結果を反映します。別ブラウザー、別端末、別ポート、`localhost` と `127.0.0.1` の間では共有されません。
- 管理者ページ最下部の削除ボタンから仮パスワード `0000` を入力すると、約4.2秒の消去演出を経て「このページは見つかりません」と表示します。実行開始時に終了状態を保存し、再読み込みや表側への移動でも終了状態を維持します。
- 削除はゲーム演出です。実ファイルやサーバーは消去しません。ランダムURL・パスワードは謎解き用で、本当の認証機構ではありません。仮シナリオには `0000` へつながる手掛かりを入れています。

## 制作中のリセット

対象サイトを開いたブラウザーの開発者ツールのコンソールで、以下を実行して再読み込みしてください。そのオリジンの投稿・公開状態・ゲームクリア状態だけを初期化します。

```js
localStorage.removeItem('kirihara-arg-v1');
location.reload();
```

## 確認項目

PCとスマートフォンの配置、噂／管理者紹介の開閉、投稿→保留→公開→トップ5反映、ロゴの9回／10回の境界、誤パスワード、正しいパスワードでの消去演出と再読み込み後の終了表示を確認します。既存の地図検索と事故詳細も回帰確認の対象です。見た目の好みや謎の難易度は、仮テキストを差し替えながら調整してください。
