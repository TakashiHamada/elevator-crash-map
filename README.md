# 三栖田えれ(β)

「ミスターエレベーター」PS5版のプロモーション用に制作した、全8ページ・約30分想定のWebARGです。閉鎖された事故マップのアーカイブをたどり、管理人の正体と事故の背景を調べます。

HTML・CSS・標準JavaScriptだけで動作します。バックエンド、外部地図API、依存パッケージは不要です。地名・人物・事故・新聞・書き込みはすべて架空です。

## 起動

プロジェクトのディレクトリで次を実行してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで [http://127.0.0.1:8000](http://127.0.0.1:8000) を開きます。Node.jsがある場合は `npm start` でも起動できます。ESモジュールを使うため、HTMLファイルを直接開くのではなくHTTP経由で閲覧してください。

## 8ページの構成

| ページ | 内容 |
| --- | --- |
| 1 | 閉鎖のお知らせ、管理者ログイン、WEBアーカイブへの入口 |
| 2 | インターネット魚拓。サイト名・現在のサイトURLから検索 |
| 3 | 最新アーカイブ。修正済みプロフィールと、その修正に言及する掲示板 |
| 4 | 中間アーカイブ。数字の手掛かりを含むプロフィール、兄の失踪の話 |
| 5 | 最古アーカイブ。2018年11月27日の事故記録1件 |
| 6 | 黒背景の管理者画面。考察メモ、復元・閉鎖操作 |
| 7 | 復元された事故マップ。新着ニュース、現場の投稿、閲覧人数と掲示板の変化 |
| 8 | クリア画面、X共有、本編への案内（閉鎖後、1ページ目を5秒表示し、3秒かけて暗転してから表示） |

メニュー、スレッド、施設情報、管理人プロフィール（左メニュー「管理人について」）は各ページ内の表示です。全8ページ共通のフッターには、ゲームの外側の情報（「このページについて」と現在のページ／総ページ数）だけを載せています。URLはハッシュルートなので、静的ホスティングでもページ別のサーバー設定は不要です。旧管理者HTMLのURLからは、新しい管理者画面へ移動します。

## 操作と保存

- 地図はドラッグ・ピンチ・ホイール・＋／−で移動・拡大縮小できます。地図自体にフォーカスした場合は矢印キーと＋／−も利用できます。
- 赤い印を押すと事故記録と口コミ、青い印を押すと目撃・証言が開きます。凡例のボタンで各レイヤーを切り替えられます。施設情報を開ける建物は地図上で色付けしてあり（色は `style.css` の `--facility-fill` / `--facility-stroke`）、拡大すると施設名と番地も表示されます。
- 保存されたページでは投稿・ログインを無効にしています。当時のページをそのまま見せるため、ボタンは表示したまま、押しても反応しないようにしています。
- ニュースには本文のコピーボタンがあります。クリップボードを利用できない環境では、手動でコピーするための欄を表示します。
- 魚拓（WEBアーカイブ）は最後に検索した語を覚えており、検索語なしで開くとその検索結果を表示します。
- 進行・初回の日付・演出の開始時刻・魚拓の検索語はlocalStorageに、管理者ログインはsessionStorageに保存します。別のブラウザーには共有されません。
- 保存できない環境でも、そのタブを開いている間は進行できます。再読み込み時の保存は保証されない旨を画面に表示します。
- クリア後の「最初から遊ぶ」で、そのブラウザーの進行を初期化できます。

ログインは物語上の仕掛けであり、実際の管理機能や秘密情報は扱いません。入力内容が外部へ送信されたり、実際の掲示板へ投稿されたりすることはありません。X共有は投稿画面を開く操作です。

## 制作時の調整箇所

| ファイル | 調整内容 |
| --- | --- |
| `board-data.js` | サイト名と魚拓検索で受け付ける表記、パスワードとヒント・入力例（`passwordHint` / `passwordPlaceholder`）、プロフィール、考察メモ（強調段落の指定を含む）、掲示板、ニュース本文、追加される事故記録、演出時間・閲覧人数の推移、閉鎖からクリア画面への演出時間（`closingNoticeHold`：閉鎖ページの表示、`closingFadeDuration`：暗転）、「このページについて」・共有文、販促リンク |
| `data.js` | 地名、施設、所在地、竣工年、設備情報、事故記録、目撃・証言、地図の操作感（`MAP_CONFIG`：ズーム、縮尺、ラベルの大きさ、選択時の寄せ方、ホイール感度、矢印キーの移動量） |
| `map-layout.js` | 生成画像に合わせて登録した施設・歩道・地名・橋・線路の座標、画像寸法と指紋 |
| `style.css` | 冒頭の色・文字サイズ・左メニューの幅（`--sidebar-width`）・地図の高さ、および各画面のスタイル |
| `game-state.js` | 進行条件、入力判定、アーカイブ検索、保存と復帰 |
| `community.js` | 公開サイトの部品（地図の枠・スレッド・ニュース・プロフィール・新着情報・投稿画面）のHTMLと、エスケープ・日付表示の共通処理 |
| `map.js` | 生成地図画像へのラベル・事故・目撃ピンの重ね合わせ、地図操作 |
| `app.js` | 8画面の遷移と各画面の外枠（ヘッダー・フッター・管理者画面・クリア画面）、時間経過による表示更新、フォーム操作 |

`CONFIG.siteUrl` は公開URLが確定したら指定してください。空欄では実行中のサイトURLを使います。魚拓のURL検索とX共有に共通で使われます。

`CONFIG.promotionUrl` は、現時点では公式ゲームページです。PS5ストアURLが確定したら、`promotionLabel` と一緒に差し替えてください。発売日の表示は提供情報に合わせて「2026年11月27日（金）」としています。

最新の魚拓の日付は初回プレイ日の前日（日本時間）です。同じプレイ中に日をまたいでも変化しません。中間は2024年10月18日、最古は2018年11月28日の保存としてあります。

地図の背景は内蔵画像生成で作成した `assets/misuta-realistic-map.png`（1536×1024）です。実在の地図を取り込んだものではありません。モデル名はツール側で指定できないため、特定モデルで生成されたとの保証はしていません。生成に使った全文プロンプトは `assets/misuta-realistic-map.prompt.txt` に保存しています（生成時の記録のため、本文の都市名は旧称の Kirihara のままです）。

生成画像の建物の輪郭を解析し、30施設の位置を登録しました。事故はその建物、6件の目撃・証言は近くの歩道・駅前広場に配置しています。住所と建物情報はデータ側で管理し、ラベルとピンを同じ座標系で重ねています。画像を差し替える際は `map-layout.js` の位置と画像の指紋も更新してください。初期案のPNGは参考素材として残していますが、現在の画面には使用していません。

## 脚本から補完した設定

- 舞台は「三栖田市」（旧称の霧原市から変更）。川は三栖川、事故現場の地区は凪浜町（既存のWebARG作品と地名が重なるため、旧称の汐見町から変更）。
- 未指定だった事故現場は「旧凪浜第三ビル」、住所は「凪浜町3丁目6番地」。
- 未指定だったニュースを架空の「三栖田日報」の記事として作成。南東部・三栖川東岸・線路より南・凪浜大橋より河口側・5階建てという情報を含めています。
- 地図では対象建物の隣接区画を空地にし、竣工年・設備更新記録も確認できるようにしています。
- 初期の事故18件と30施設、6件の目撃・証言を作成。事故記録の最初は2018年11月27日とし、それより前の事故は含めていません。
- 脚本の指定外の噂、口コミ、拡散後の書き込みを補完しました。
- 出典入力については、脚本の「記事タイトル」と「ニュース記事内容をコピペ」の両方の記述に対応。タイトル単体、本文、本文を含む記事全文を受理し、文字幅・空白・改行の差を吸収します。
- 最古のプロフィールには、当時の年齢と矛盾しない簡単な自己紹介だけを掲載しています。

## 自動検証

Node.js 20以降で実行できます。依存パッケージのインストールは不要です。

```sh
npm run check
npm test
```

`npm run check` は全モジュールとテストの構文を確認します。`npm test` では、進行条件、アーカイブの情報差、ニュースの5秒待機（`CONFIG.newsDelay`）、正誤の投稿、閲覧人数と投稿の増加、重複実行防止、保存・復帰・保存拒否時の継続、ルート制限、施設データの整合を検証します。地図についてはPNGの画素を直接読み、施設の中心が建物の上にあること、目撃地点が歩道・広場の上にあること、水面を避けていること、保存日以降の目撃情報が混入しないこと、拡大縮小で縮尺が一致することも確認します。

`CONFIG.newsDelay` を変えると、変更前に保存された「掲載済み」の進行は無効になり、最初からになります。

## 人間に確認してほしい点

見た目・手触り・難易度は、人間による確認をお願いします。

1. PCとスマートフォンで、文字の大きさ、地図の操作、施設情報の読みやすさを確認する。
2. 魚拓から保存一覧へ戻り、3世代のページを迷わず比較できるか確認する。
3. 謎の手掛かりの分かりやすさ、管理人の長文メモの読み心地を確認する。
4. 地図とニュースから場所を特定し、記事をコピーして投稿する流れを確認する。
5. 現場公開後の掲示板・閲覧人数の変化が、再閉鎖の動機につながるか確認する。
6. クリア文、Xの共有文、PS5販促文とリンク先を確認する。
7. 地図で施設情報のある建物の色付けが見分けやすく、事故現場のビルだけが目立っていないか確認する。
8. 閉鎖ページの5秒表示と3秒の暗転の体感、1ページ目の「WEBアーカイブを利用する」の見つけやすさを確認する。

途中で初期化したい場合は、ブラウザーの開発者ツールで次を実行してください。

```js
localStorage.removeItem('misuta-ere-story-v1');
localStorage.removeItem('misuta-ere-archive-query-v1');
sessionStorage.removeItem('misuta-ere-admin-v1');

```

旧プロトタイプの `kirihara-arg-v2` の保存内容は、新しい進行には引き継ぎません。
