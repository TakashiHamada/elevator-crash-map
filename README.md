# エレベーター事故マップ

架空の霧原市を舞台にした ARG の静的プロトタイプです。HTML、CSS、JavaScript のみで動き、バックエンドや外部地図 API は使用しません。

## 起動

このディレクトリで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8000` にアクセスします。保存状態をページ間で共有するため、HTTP 経由で開いてください。

## 画面と操作

- PC では左に掲示板、右に事故マップを表示します。掲示板全体をスクロールすると、最後の投稿に続いて情報提供欄が現れます。
- スマートフォンの縦画面では「掲示板」「マップ」タブで画面を切り替えます。右端のメニューから、このページについて、管理人について、管理人ページ、開発者向け情報を開けます。
- マップ上の赤い「!」マーカーから詳細を開けます。ドラッグ、ピンチ、ホイール、＋／−で移動や拡大縮小、⌖ で表示範囲を戻せます。
- 情報提供は本文だけを入力します。原文は掲示板に直接載りません。通常の文章は管理人ページの「届いた情報」に保存されます。特定のキーワードが含まれる場合のみ、管理人名義の定型投稿や返信が掲示板に加わります。
- ヘッダーまたはスマートフォンのメニューから管理人ページへログインします。ログアウトするとトップへ戻ります。管理人ページには考察メモ、届いた情報、ログイン履歴を表示します。履歴の「削除」はその項目をこのブラウザー上で非表示にします。

## 制作時の調整

- `board-data.js`：ログイン情報、初期投稿、反応キーワード、管理人の返信・編集済み投稿、考察メモ、サンプル履歴。確認用の値は画面内の「開発者向け情報」にも表示されます。
- `data.js`：事故記録、地図ラベル、座標、ズーム設定。
- `style.css`：掲示板幅（`--board-share`）、色、文字サイズ、マーカーサイズ（`--marker-size`）など。
- `community.js`：掲示板、情報提供、ログイン、履歴削除、モバイルタブ、ブラウザー保存。
- `app.js`：地図の操作と事故詳細。

情報提供、掲示板の進行、履歴削除は localStorage に、管理人ページのログイン状態は sessionStorage に保存されます。同じオリジンのブラウザー内だけで共有され、外部には送信されません。現在の認証は静的サイト上の演出であり、開発者向け情報にも認証情報を表示します。本番公開で実際のアクセス制限が必要な場合はサーバー側の認証へ変更してください。

## 初期状態に戻す

対象サイトを開いたブラウザーの開発者ツールで以下を実行し、再読み込みします。

```js
localStorage.removeItem('kirihara-arg-v2');
sessionStorage.removeItem('kirihara-admin-session');
location.reload();
```

地名、建物、事故、出典はすべて架空です。地図は一枚の画像のため、ズームしても道路情報は増えません。
