# エレベーター事故マップ

架空の「霧原市」を舞台にしたWeb ARGの静的プロトタイプです。HTML・CSS・JavaScriptのみで実装しており、外部ライブラリ、地図API、ビルド、APIキーは不要です。

## 起動

`index.html` をブラウザーで開いてください。ローカルサーバーを使う場合は、このディレクトリで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、`http://localhost:8000` にアクセスします。

## 操作

- 地図のドラッグ、ホイール、＋／−、タッチのピンチで移動・拡大縮小。
- 赤い事故アイコンを選択すると記録を表示。
- 町名・建物名・記録番号の検索、発生年代による絞り込み。
- ⌖ で表示・検索条件をリセット。
- 記録のURLは `#record=KR-010` などで直接指定可能。リンクコピーにはブラウザーのクリップボード許可が必要な場合があります。
- 地図にフォーカスして矢印キーで移動、＋／−でズーム。Escで記録を閉じる。

## 編集

- `data.js`：事故記録、地図ラベル、座標、ズーム設定。座標は元画像に対する0〜100の百分率。
- `style.css`：色、文字サイズ、マーカーサイズ（`--marker-size`）など。
- `assets/kirihara-map.png`：生成した架空の街の地図。
- `assets/elevator-crash.png`：生成した破損エレベーターアイコン。

地図は一枚の画像なので、ズームしても道路情報が増える方式ではありません。市外の実在地図には接続しません。小さな画面では一部が画面外になりますがドラッグして閲覧できます。投稿・バックエンド・外部送信はありません。

参考UI：https://www.oshimaland.co.jp/ （地図・地点アイコン・検索・記録閲覧という構成を参考にし、左の一覧は省略。）

## 画像生成

内蔵 image_gen で生成。プロンプトは `assets/prompts.md` に保存しています。地図・建物・事故・出典はすべて架空です。
